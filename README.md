 🍫 BakedCharmm

Baked with Love. Happiness is Homemade.

BakedCharmm is a single-page website for a small home bakery that makes fresh brownies, fudge slices and cookies in small batches. Visitors can read about the bakery, browse the menu, work out the cost of their treats, and place an order.
